# IntiVentory Visual Identity & Branding Guide

**Document Status:** Source of truth for IntiVentory visual identity, typography, color palette, and design principles.

---

## Approved Identity & Naming

* **App Display Name:** IntiVentory
* **Telugu Name (Pronunciation):** ఇంటి వెంటరీ
* **Telugu Tagline:** మన ఇంటి సరుకులు, మన ఇంటి లెక్కలు.
* **English Translation:** *Our household supplies, our household accounts.*
* **Etymology:** *Inti* (ఇంటి — household/home in Telugu) + *Inventory*.

> [!NOTE]  
> **Technical Identifiers:** The repository is named `IntiVentory-Android`. The Android application ID is `com.boyidapu.homestock`. The application ID is a technical identifier and must remain unchanged to preserve database pathing and package declarations.

### Design Concept
A rounded Deep Teal tile containing a clean white home outline and shelf, accompanied by Soft Sage household product accents. The wordmark uses Deep Teal typography, and the Telugu tagline appears directly beneath it.

## Approved Color Palette

| Color Role | Color Name | Hex Code | Material 3 Usage |
| :--- | :--- | :---: | :--- |
| **Primary** | Deep Teal | `#2F6B62` | Primary buttons, app bar title, selected navigation items, key headers |
| **Accent** | Soft Sage | `#B9D0C0` | Card borders, category accents, quiet icons |
| **Main Background** | Warm Mist | `#F4F6F0` | Screen container background |
| **Surfaces / Cards** | Clean White | `#FFFFFF` | Card surfaces, form inputs, dialog backgrounds |
| **Main Text** | Forest Charcoal | `#273832` | High-emphasis body text and input fields |
| **Secondary Text** | Muted Sage-Gray | `#52665C` | Subtitles, date range labels, secondary details |

## User Interface Guidelines

* **Calm & Uncluttered:** Designed for fast, stress-free daily household use.
* **Material 3 Light Theme:** Light-first palette using Deep Teal and Soft Sage tokens.
* **Numeric Readability:** Prominent, formatted INR spending totals (`₹`) with paise precision.
* **Typography & Glyphs:** System default fonts supporting clean Telugu glyph rendering on native Android devices.
* **Prohibited Visuals:** Avoid neon colors, dark-mode gradients, aggressive shadow effects, heavy decorative illustrations, or unnecessary animations.
